02 code

All of it is code.

A brand is one BRAND.md, one specimen page and the scripts that made it, so any asset rebuilds in one command.

brand/ BRAND.mdthe system, written down specimen.htmlthe system in use: hero, type scale, tokens, motion references.mdwhat was taken from your saves, and what wasn't logo/gen.mjsthree marks from real font outlines, as SVG paths copy/ MESSAGING.mdthe one line, what it is and isn't, the voice, facts with sources SITE.md LAUNCH.md README.md site/static, on Vercel: og.png, favicon.svg, the README header video/HTML scenes on one clock, sound built from the same clock

03 checks

Checked before it says done.

Two scripts ship with the skill. One shoots a page at 45 widths in light and dark and prints anything that overflows. The other renders the video frame by frame and prints its loudness after encoding.

$ bun shoot.mjs site/ shots/
page scrolls sideways by 14px
  at light 320, dark 320
text wider than its box: strong.num "~2,000"
  at light 1035, dark 1035

2 problems · shots in shots/ at 390@2x, 1035, 1440

$ bun video.mjs video/ video
41s / 41s
video/out/video.mp4: -14 LUFS, true peak -2.1 dBTP after AAC

04 install

Install

One command. Then open a project in Claude Code and say brand it.

npx skills add AVGVSTVS96/brand-it

You'll need
Bun, Chrome and ffmpeg, for the scripts. Bun installs puppeteer-core on first run.

It points at my own projects and saves, so read it as a worked method, or fork it and point it at yours.
